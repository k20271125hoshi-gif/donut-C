# DONUT MATCH V3

文化祭のドーナツ販売向け、HTML / CSS / JavaScriptのみで動くオペレーションUIです。

## 3つのメインタブ

1. **販売** — 主機能。注文受付、注文番号発行、客と商品の照合、受け渡し、在庫管理
2. **拠点状況** — 体育館横・販売所 / 家庭科調理室 / 運搬・連絡 の忙しさをLv.1〜5で表示
3. **ヘルプ** — 人数・理由・緊急度を指定して応援要請。対応中 / 解決まで管理

スマホ版ではInstagramのように画面下部へ3タブを固定します。PCでは画面上部のタブで切り替えます。

## この端末の場所

画面上部の「この端末の場所」で、端末を置く拠点を選択します。
拠点状況タブでは、その端末が属する拠点の忙しさだけを更新できます。

## 起動

`index.html` をブラウザで開くだけでも動作します。

より安定して使う場合:

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## データ保存

注文・在庫・忙しさ・応援要請は `localStorage` に保存します。同じブラウザの別タブ/ウィンドウ間では `BroadcastChannel` と `storage` イベントで更新を反映します。

## 本番運用で重要

このV3は静的サイトなので、**体育館横のスマホと家庭科調理室のスマホなど、別端末間でのリアルタイム同期はまだ行いません**。
本番で3拠点の端末を同期するには Firebase / Supabase 等の共有データベースを接続します。UIはその接続を追加しやすい構成にしてあります。

第三拠点名は現在「運搬・連絡」です。実際の役割名が決まったら `app.js` の `LOCATIONS.transport` を変更してください。
